# 🧮 Protean Calculator

> A modern, elegant, and fully responsive Scientific Calculator built for precision and usability.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Build](https://img.shields.io/badge/build-passing-brightgreen)
![Version](https://img.shields.io/badge/version-1.1.0-orange)

Protean Calculator is a highly functional Scientific Calculator Web Application built using native web technologies (HTML, CSS, JavaScript) and styled with Tailwind CSS. It features a sleek dark-mode UI, comprehensive scientific functions, and a real-time calculation history, making it perfect for students, professionals, and developers.

## ✨ Key Features

- **📱 Fully Responsive Design**: Seamless experience across desktop, tablet, and mobile devices.
- **🔢 Advanced Scientific Functions**: Includes trigonometric (`sin`, `cos`, `tan`), logarithmic (`log`, `ln`), exponential (`e`, `xʸ`), and square root (`√x`) operations.
- **🔄 Degree & Radian Modes**: Easily switch between angle units for precise trigonometric calculations.
- **📜 Calculation History**: Keep track of your past calculations, view them, and reuse results instantly.
- **⌨️ Full Keyboard Support**: Perform calculations quickly and directly using your keyboard.
- **🎨 Modern UI/UX**: Styled with Tailwind CSS to provide a minimal, beautiful, and distraction-free dark theme.
- **🛡️ Robust Error Handling**: Gracefully handles floating-point anomalies and syntax errors with safe evaluation contexts.

## 🧠 Supported Operations

| Type | Functions |
|---|---|
| **Basic** | Addition (`+`), Subtraction (`-`), Multiplication (`×`), Division (`÷`), Modulus (`%`) |
| **Scientific** | `sin(x)`, `cos(x)`, `tan(x)`, `log(x)`, `ln(x)`, `√x`, `xʸ` |
| **Constants** | `π` (Pi), `e` (Euler’s Number) |
| **Modes** | `DEG` / `RAD` toggle for trigonometric calculations |
| **History** | View, clear, and reuse previous results from the sidebar |

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and layout
- **Tailwind CSS**: Utility-first CSS framework for modern styling and responsive design
- **JavaScript (ES6+)**: Core logic, functional evaluation, and dynamic interactivity

## 💻 Getting Started

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/abhranilsingharoy-cloud/Protean-Calculator.git
cd Protean-Calculator
```

### Usage

No build tools or package managers are required. Simply open the `index.html` file in your preferred web browser:

```bash
# On macOS
open index.html

# On Windows
start index.html

# On Linux
xdg-open index.html
```

## ⚙️ Deployment via GitHub Pages

1. Go to your GitHub repository settings.
2. Navigate to **Pages** in the left sidebar.
3. Under **Source**, select the `main` branch and the `/ (root)` folder.
4. Click **Save**. Your project will be live in a few minutes!
